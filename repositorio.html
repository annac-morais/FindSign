JavaScript

JavaScript é uma linguagem de programação usada para adicionar interatividade e dinamismo às páginas web.

Java

Java é uma linguagem de programação orientada a objetos, amplamente usada em aplicativos, sistemas corporativos e Android.

C#

C# é uma linguagem de programação criada pela Microsoft, usada para desenvolver aplicações desktop, web e jogos.

HTML

HTML (HyperText Markup Language) é uma linguagem de marcação usada para estruturar o conteúdo das páginas da web.

CSS

CSS (Cascading Style Sheets) é uma linguagem de estilo usada para definir o design, cores e layout de páginas web.

Algoritmo

Algoritmo é um conjunto de instruções ordenadas para resolver um problema ou executar uma tarefa específica.

API

API (Application Programming Interface) permite que diferentes sistemas e aplicações se comuniquem entre si de forma padronizada.

Backend

Backend é a parte do sistema responsável pelo processamento, lógica de negócio e comunicação com banco de dados, invisível para o usuário.

Frontend

Frontend é a parte do sistema visível ao usuário, responsável por interfaces, design e experiência do usuário.

Fullstack

Fullstack refere-se a desenvolvedores que trabalham tanto com frontend quanto com backend, compreendendo toda a aplicação.

Código Fonte

Código Fonte é o conjunto de instruções escritas por programadores em linguagens de programação que definem o funcionamento de um software.

VPN

VPN (Virtual Private Network) cria uma conexão segura e criptografada entre o dispositivo do usuário e a internet, protegendo dados e identidade.

Open Source

Open Source são softwares cujo código-fonte é aberto, permitindo que qualquer pessoa estude, modifique e distribua livremente.

Tecnologia

Tecnologia é o conjunto de conhecimentos, técnicas e ferramentas utilizadas para criar, desenvolver e aprimorar produtos, serviços e soluções digitais ou físicas.

Wireframe

Wireframe é uma representação visual simples da estrutura de uma interface, focando na organização e funcionalidade sem detalhes de design.

Design System

Design System é um conjunto de padrões, componentes e diretrizes de design que garante consistência e eficiência em interfaces digitais.

Atomic Design

Atomic Design é uma metodologia que divide a interface em componentes menores (átomos, moléculas, organismos), facilitando construção e manutenção.

Style Guide

Style Guide é um guia visual que define cores, tipografia, ícones e outros elementos para manter consistência em produtos digitais.

Figma

Figma é uma ferramenta de design de interface e prototipagem colaborativa, utilizada para criar layouts, wireframes e protótipos interativos.

Acessibilidade

Acessibilidade garante que interfaces digitais possam ser utilizadas por todas as pessoas, incluindo pessoas com deficiências visuais, auditivas ou motoras.

CorelDraw

CorelDraw é um software de design gráfico vetorial usado para criar ilustrações, logotipos, layouts e materiais visuais profissionais.

AutoCAD

AutoCAD é um software de desenho técnico assistido por computador (CAD) usado para projetar plantas, peças mecânicas, engenharia e arquitetura.

Bug

Bug é um erro, falha ou comportamento inesperado em um sistema ou software que causa funcionamento incorreto ou indesejado. Geralmente é investigado com logs, testes e debugging para encontrar e corrigir a causa.

Codar

Codar significa programar, escrever e organizar códigos em linguagens de programação para criar softwares, aplicativos e sistemas digitais.

Hack

Hack pode significar uma solução rápida (workaround) para um problema ou, em outro contexto, exploração de vulnerabilidades. Em práticas positivas, refere-se a criatividade para resolver algo; em segurança, refere-se a atividades que exploram falhas.

Inteligência Artificial

A Inteligência Artificial (IA) é a área da computação que cria sistemas capazes de executar tarefas que normalmente exigem inteligência humana — como reconhecer padrões, tomar decisões e aprender com experiências. Ela está presente em assistentes virtuais, carros autônomos e ferramentas de análise de dados.

React

React é uma biblioteca JavaScript criada pelo Facebook para construir interfaces de usuário dinâmicas. Baseia-se em componentes reutilizáveis, permitindo criar sites e aplicações com melhor desempenho e manutenção simplificada.

Angular

Angular é um framework front-end desenvolvido pelo Google, usado para criar aplicações web dinâmicas. Ele utiliza TypeScript e oferece uma arquitetura robusta para desenvolvimento escalável.

Streaming

Streaming é a transmissão contínua de áudio, vídeo ou dados pela internet, sem necessidade de download. É a base de plataformas como Netflix, Spotify e Twitch.

MetaIA

MetaIA refere-se a um conceito de inteligência artificial em evolução, que aprende e melhora continuamente suas próprias capacidades. Representa uma IA que analisa e otimiza outras IAs ou sistemas, buscando desempenho e eficiência superiores.

ChatGPT

ChatGPT é um modelo de linguagem baseado em IA desenvolvido pela OpenAI. Ele é capaz de compreender e gerar texto em linguagem natural, auxiliando em conversas, explicações, programação e criação de conteúdo.

DeepSeek

DeepSeek é um modelo de IA avançado focado em raciocínio profundo, busca de informações e resolução complexa de problemas. Foi projetado para análises detalhadas e tarefas de alta precisão em aprendizado de máquina.

Microsoft Azure

Microsoft Azure é uma plataforma de computação em nuvem desenvolvida pela Microsoft que fornece serviços como hospedagem, inteligência artificial, armazenamento e integração de dados. É amplamente usada por empresas e desenvolvedores para criar, implantar e gerenciar aplicativos em escala global.

Gemini

Gemini é a família de modelos de IA desenvolvida pelo Google DeepMind, que combina raciocínio, texto, imagem e código. É voltada para compreensão multimodal e interação mais natural entre humanos e máquinas.

Alexa

Alexa é um assistente virtual desenvolvido pela Amazon, capaz de interpretar comandos de voz, controlar dispositivos inteligentes e auxiliar em tarefas do dia a dia com inteligência artificial.

Zoom

Zoom é uma plataforma de videoconferência que permite reuniões online, webinars e colaboração em equipe, sendo amplamente utilizada por empresas, escolas e profissionais.

YouTube

YouTube é uma plataforma de compartilhamento de vídeos online, permitindo que usuários assistam, publiquem e interajam com conteúdos audiovisuais de todo o mundo.

TikTok

TikTok é uma plataforma de vídeos curtos que permite criar, editar e compartilhar conteúdos com efeitos, músicas e filtros, sendo muito popular entre jovens e criadores de conteúdo.

Google Chrome

Google Chrome é um navegador web desenvolvido pelo Google, conhecido por sua velocidade, segurança e suporte a extensões que ampliam suas funcionalidades.

Google Classroom

Google Classroom é uma plataforma educacional que permite criar, distribuir e avaliar tarefas online, facilitando a comunicação entre professores e alunos de forma prática e organizada.

Apple

Apple é uma empresa de tecnologia conhecida por seus produtos como iPhone, iPad, Mac e serviços digitais, destacando-se pelo design, inovação e integração de hardware e software.

WhatsApp

WhatsApp é um aplicativo de mensagens instantâneas que permite enviar textos, áudios, vídeos, fotos e realizar chamadas de voz e vídeo de forma gratuita pela internet.

Telegram

Telegram é um aplicativo de mensagens que oferece chats rápidos e seguros, com foco em privacidade, grupos grandes e recursos avançados como bots e canais de transmissão.

Amazon

Amazon é uma empresa de comércio eletrônico e serviços de nuvem, oferecendo uma ampla variedade de produtos, entregas rápidas e soluções digitais como Amazon Web Services (AWS).

Microsoft

Microsoft é uma empresa de tecnologia que desenvolve softwares, serviços em nuvem e dispositivos, conhecida pelo Windows, Office e soluções corporativas para empresas de todos os portes.

Samsung

Samsung é uma empresa de tecnologia global que fabrica eletrônicos, smartphones, TVs e soluções de TI, sendo conhecida por inovação e diversidade de produtos.

Twitch

Twitch é uma plataforma de streaming de vídeos ao vivo, focada em jogos, música e cultura, permitindo que criadores transmitam conteúdo em tempo real para uma comunidade global.

Android

Android é um sistema operacional desenvolvido pelo Google, baseado em Linux, usado em dispositivos móveis e conhecido por sua flexibilidade e ampla compatibilidade com aplicativos.
